# Petualangan Tata Surya 🪐

Game edukasi interaktif materi **Tata Surya** untuk siswa SD Kelas 6.
Dibuat dengan **Google AI Studio** (fitur Build) tanpa menulis kode.

## Fitur
- 3 nyawa hati, skor poin, timer 15 detik per soal
- 10 soal tantangan, 3 level orbit (mudah → sulit)
- Efek suara, animasi, umpan balik langsung
- Bintang penilaian & layar skor akhir

## Cara Menjalankan
```bash
npm install
npm run dev
```
